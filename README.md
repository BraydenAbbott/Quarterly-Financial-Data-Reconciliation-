# Traveling Scholar Club - Financial Reconciliation Model

## Business Scenario (Context)
The Traveling Scholar Club required a digitized financial tracking system to consolidate quarterly operating expenses. The previous system was manual and prone to calculation errors. This project involved migrating their expense data into a structured Excel model to automate year-end reporting.

## Technical Objectives
*   **Data Structure:** Organized raw expense categories across 4 distinct fiscal quarters.
*   **Automated Logic:** Implemented dynamic formulas (`SUM`, `AVERAGE`) to instantly calculate quarterly burn rates and annual totals.
*   **Formatting Standards:** Applied accounting currency formats and conditional layouts to ensure the ledger is print-ready for board meetings.
